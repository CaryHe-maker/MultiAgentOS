# mdhtml oracle design

The oracle forwards the input to `cmark --unsafe` (version 0.30.2, the version whose behaviour the
hidden tests record) and returns its output unchanged. Because the expected outputs of the composite
documents were generated by the same program, and all 652 specification examples agree with it, the
oracle passes every rendering test; this validates the test data rather than any Markdown logic.

A real implementation follows the specification's appendix: parse blocks line by line into a tree of
open containers, close and finalize blocks, collect link reference definitions, then parse the
inline content of paragraphs and headings with the delimiter stack ("process emphasis") and the
bracket stack for links and images, and finally render HTML with the escaping rules.
