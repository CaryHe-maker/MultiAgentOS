# MultiAgentOS SharedContracts

## 1. 定位

SharedContracts 是公共契约静态库，表达模块和组件协作所需的共同概念。
它不作为基础设施服务运行，不保存具体模板、执行实例或权限状态，
也不包含业务推进、授权、调度与执行算法。

AgentToolPool 使用契约描述模板，ExecutorSet 使用契约表达行为输入输出，
Module 使用契约交接请求与事实。

## 2. 概念范围

公共契约涵盖用户意图、业务运行、操作请求、执行结果、产物引用、错误和系统控制。
Agent、Unit、Tool 与 Executor 的关系需表达模板组合、受保护能力声明、面向模型的工具描述和原子行为的区别。

Lease 是 Core 的私有权威对象，不作为跨边界共享实体。
公共契约可以表达权限检查请求、裁决结果和操作关联，但不能携带可复用 Lease 副本。

## 3. 边界与版本

跨边界数据具有明确语义和适用版本，接收方校验其来源、结构和上下文。
未知或不兼容内容不能被静默解释为成功，也不能根据字段偶然存在猜测含义。

模板与实现的版本、业务图版本、结果和产物的历史关系必须可辨识，
契约变更不能原地改变已发布事实的语义。
公共结构不意味着模块可以共享可变内部对象。

## 4. 引用与完整性

大对象使用受控引用，引用与正文具有可验证的完整性关系。
持有引用不授予访问权；凭据和内部句柄不能作为普通共享数据传播。
需要比较或验证的内容必须具有一致的解释规则，不因传输方式变化而产生不同语义。

## 5. 共同验证

生产者和消费者共享行为约定，验证正常输入、未知版本、失效引用、
不完整结果、重复与迟到消息，以及声明能力与实际行为不符的情况。
契约验证不代替 Core 授权或 Workflow 验收。

长期协作关系见 [Protocol](../Protocol.md)。
