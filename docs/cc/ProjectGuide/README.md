## 五分钟速读版

1. **项目是什么：** 让 AI 自己读代码、改代码的命令行工具，最终能让多个 AI 分工。M1 只做只读的“仓库分析助手”：你提问题，它搜索、读代码，交出每句话都标明出处的报告。
2. **核心理念：** 模型只能提议，Kernel 负责执行和把关；每个模块只管自己的事，通过接口协作；每一步都有记录和出处；先做最小的一步，但给以后留扩展位置；最终目标是多 Agent 协作。
3. **五个模块：** UserInteraction 是前台，Workflow 是项目经理（Cary），Kernel 是管理员兼执行员（田园），ContextEngine 是资料员（你），AgentToolPool 是人事档案。
4. **代码现状：** 管道已经铺好（格式校验、安全读文件、模块启动），但水还没通：模型没接上，Agent 循环还没写。
5. **最缺的东西：** 模型动作（AnalysisAction）、调模型的输入输出、步骤记录、最终报告，这几个数据格式。定下来，三个人就能同时开工。
6. **周日会议你的立场：** 做最小有效单元，但把扩展点留好；逐项定下接口清单；约定第一次联调的日期。
